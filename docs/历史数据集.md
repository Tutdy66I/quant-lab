# 长期历史数据集 V1

目标是让数据来源、采集时点、完整性检查和研究方案可以复核。本版采用单一交易所的 BTC/USDT 历史归档，不修改 Kraken BTC/USD 基线与 MA20/60 前瞻模拟账户。

## 来源与保存

- 官方入口：[Binance Data Collection](https://data.binance.vision/)。格式、校验及修订说明：[官方仓库](https://github.com/binance/binance-public-data)。
- 固定覆盖 2018-01-01 至 2026-09-30，共 105 个完整月、3195 根 UTC 日线。只使用完整月，2026 年第四季度不混入本版。
- `data/history/binance_btcusdt_1d_v1/raw/` 保存每月 ZIP 与官方 `.CHECKSUM`，`manifest.json` 保存下载 URL、UTC 采集时间、ETag、Last-Modified、包指纹和覆盖范围。
- `ohlc.csv` 保留来源 OHLC 小数文本，统一时间戳为 UTC 秒。2025 年前的毫秒与其后的微秒按官方格式处理，并严格核对开盘和收盘时间。
- 原始字节禁止 Git 换行转换。CSV、ZIP、校验文件和 manifest 均带指纹；校验时从 ZIP 重建 CSV，拒绝修改、缺失、重复、跳日或无效价格。无插值补齐。

## 使用

默认数据已保存，日常研究离线运行：

```console
python -m strategies.history verify
python -m strategies.history_study
python -m strategies.cross_source verify
```

重新采集需要联网，必须显式指定新的版本目录，已有目录会被拒绝：

```console
python -m strategies.history collect --dataset data/history/binance_btcusdt_1d_v2 --start 2018-01 --end 2026-09
```

数据在临时同级目录通过完整校验后才发布。失败时不留下可被误用的半成品数据集。官方归档可能修订，因此新版可能与旧版指纹不同；必须比较后再采用，不能覆盖旧版本。

## 固定验证

`docs/history_protocol_v1.json` 在本轮采集前保存，报告记录其 UTF-8/LF SHA-256。沿用既有 11 个候选、252 天滚动训练、63 天验证、前收盘信号和次开盘成交；单边手续费 0.1%、滑点 0.05%。2018 年提供预热与初始训练，验证从 2019-01-01 开始，保留不足 63 天的尾窗。

阶段为 UTC 自然年，最后一年截至 9 月末。按同一权益路径切片，年界继承前一日权益，不额外清仓。分窗选参与同窗基线每窗清算；另列连续 MA20/60 和连续买入持有以观察边界效应。只按历史训练净收益选参，成本压力固定原选择。不根据报告扩大候选、挑窗口或筛选年份。

输出独立保存在 `data/history_study_v1.json` 和 `docs/长期历史验证报告.md`。JSON 含逐日权益、逐窗选择、交易、分年指标、数据和代码指纹；可以从另一目录通过设置 `PYTHONPATH` 后运行模块，用 `--output-root` 写入独立位置重建。

## 尚未解决的可信度限制

官方 SHA-256 校验解决传输完整性，不证明价格绝对正确。已用 Coinbase Exchange BTC/USD 完成全部 3195 个 UTC 日期的独立对照，详见[第二来源交叉核验](第二来源交叉核验.md)。参考数据原始响应和采集记录保存在 `data/history/coinbase_btcusd_1d_v1/`，其完整性可离线复核；不向旧数据补值或替换价格。

交叉核验规则保存在 `docs/cross_source_protocol_v1.json`，先于本轮 Coinbase 下载固定：任一 OHLC 绝对相对差超过 3%，或收盘差超过 1%，列为诊断告警。阈值不表示误差置信区间；所有告警日期保留。重新采集参考源时使用 `python -m strategies.cross_source collect --reference <新的版本目录>`，拒绝覆盖。

币种基差未作换算，因此跨交易所一致性不能替代同市场价格认证。没有保存每个历史时点当时可见的原始版本，下载到的是采集时的历史归档，不可声称是 point-in-time 数据。

BTC/USDT 与 Kraken BTC/USD 具有交易所与报价币差异，不混合拼接，也不直接用收益差证明新数据更优。历史已公开且候选曾被研究，方案先于本轮计算固定仍属于回顾性验证。前瞻证据继续由原 MA20/60 模拟账户独立积累。
