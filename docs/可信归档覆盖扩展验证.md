## 预先固定的验证范围与门槛

采集之前冻结 `docs/archive_coverage_protocol_v1.json`，并将其原始字节复制进来源数据版本。共 27 个 BTCUSDT USDⓈ-M 日期：2021-12-01、2025-06-24、2026-06-01、2026-06-20 至 07-05 的连续 16 天，以及 2026-10-14 至 10-21 的连续 8 天。未按核验结果追加日期、降低门槛或搜索预测参数。

对每个 metrics 包下载当天及前一天的五分钟 K 线作为参考，比较 T 标签对应 `[T−5min,T)` 和 `[T,T+5min)` 两种解释。门槛为：两种解释都要有 288 个配对，选中解释日相关系数至少 0.99、领先另一解释至少 0.5、中位相对误差不超过 2%；四个六小时子区间分别要求 72 对、相关系数至少 0.98、领先至少 0.3。缺失、常数参考、重复标签、日内语义漂移均不能由日均相关掩盖。

这些门槛用于核验字段窗口，**不是显著性检验或预测效果筛选**。参考仍来自同一家交易所的另一类归档，不是独立交易所或独立采集者，也不等于逐笔 aggTrades 的精确重构。OI/多空比不会因 taker 检验通过而获得任何准入。

## 实际覆盖和发现

取得 27 个 metrics 包、32 个 K 线参考包及各自官方 SHA-256 校验文件，共 **59 个 ZIP**，全部通过校验。新证据目录为 `data/archive_coverage/binance_um_btcusdt_v1/`，包含 119 条文件响应/复用记录：118 个 ZIP/校验文件和 1 个当前使用条款。部分已经保存的文件复用其原始字节、指纹和原采集时间，显式标记 `reused_from`，不冒称本轮重新下载。

2025-06-24 的开始窗口 r=0.999920、前一窗口 r=0.052002；2026-06-01 开始窗口 r=0.997065、前一窗口 r=0.039304。连续 6 月样本在 6 月 25 日两侧都支持开始标签。**没有定位到真实历史切换日期，也没有证明社区在旧版本上一定错误**；结论只绑定本轮保留的精确指纹，不外推至未采集版本或区间。

11 个 metrics 文件存在原始行序倒退，包括 2026-06-01、06-28、07-05 及八个十月文件。按原始行号保留溯源后再排序；所有来源标签均为完整连续的五分钟网格，没有通过补零、插值或取整填补。

2021 年参考 K 线文件没有表头，和现代文件不同。新版研究读取器仅为已观察的 2021 格式显式支持官方十二列顺序，并核对 288 行、整日 UTC 时间网格与每条 close_time；第一条数据未丢弃。第二阶段适配器及其源码绑定的数据版本原封保留，没有扩大旧白名单或破坏旧输出的离线回放。

## OI、多空比独立核验：仍缺合格证据

本轮查看了 [Tardis 的 Binance 数据采集说明](https://docs.tardis.dev/historical-data-details/binance-futures.md)，其列出了独立保存的 OI 及账户/持仓比采集通道，是候选核验来源。但正常读取其官方许可页面时，两种页面形式均返回 **HTTP 403**；随后停止该来源，没有下载 Tardis 市场数据、使用账户密钥、切换主机或通过代理重试。没有调用受限 Binance REST API 或插件作为替代通道。

`access_diagnostics.json` 记录的是执行工具返回的状态诊断，**不是完整 HTTP 响应快照**；这两次响应体未保留，不伪造相应 SHA-256，也不声称证明供应商永远不可用。能找到下载文档不代表已取得当前使用/再分发许可。许可和正常访问条件确认前，这部分不能进入公开标准化版本。

目前以下五列全部保持隔离：`sum_open_interest`、`sum_open_interest_value`、`count_toptrader_long_short_ratio`、`sum_toptrader_long_short_ratio`、`count_long_short_ratio`。数据仍在原始 ZIP 中，`isolation.json` 记录各日期的隔离原因；没有为它们生成可用于研究的事件时间。没有将“相关市场价格/成交量”“同份 metrics 的另一个副本”误当成独立 OI 或账户比例观测。

实际独立核验仍需：同一 BTCUSDT 合约和相同计量口径；具有交易所事件时间、独立采集者到达时间和可核对的采集延迟/失联区间；明确各列的更新时间。未来应对每一列比较不同偏移并限定参考陈旧程度，检查整日及子区间，记录误差和歧义。对账户数量比和持仓比必须分别核验，不能由 OI 的结果代替。未采集到合格参考数据前，本报告不提供 OI/多空比的实际对齐误差或“已通过”结论。
