## 每日检查

当前聊天的定时跟进每天香港时间 08:25 检查。运行 `python deployment/observe.py` 归档证据；脚本只读 MA 账本，检测到 Hummingbot 人工暂停标记时记录 paused_by_user，跳过其账本、状态与公开报价请求，不将暂停算作故障。MA 采集失败时保留错误并返回非零退出码。

MA 的 daily 表是每日权益依据，final=0 表示暂定值；后续快照保存更新后的最终值。保留 trades 与 runs 的观察时间、费用、延迟及故障恢复，分别统计新增日与补跑日。

采集脚本同时生成 [纸面观察进度](纸面观察进度.md)，仅包含模拟账户汇总和数据时间。每日跟进将这份报告同步至 GitHub 当前观察分支；上传失败时保留本地记录并报告。原始 runtime 账本、日志、快照与本机配置始终留在本地。

Hummingbot 的 TradeFill 才是成交证据。快照保存原始字段，其价格和数量可能按数据库定点格式存储，统计时需按该版本类型定义解码并与 hbot history 核对。session_started_at 标识运行会话；重启会重置余额，跨会话不得拼接成连续收益。公开中点估值未扣假设平仓成本，不能与 MA 日线收盘估值直接混用。

定时跟进核对 Python 进程和 quant-lab-paper-observer 登录任务；仅首次自然成交、重要故障及恢复、需要人工操作和复盘完成时通知。人工停止标记或禁用任务优先，不能自动撤销。Hummingbot 的历史记录留存，仅供暂停前验收回顾。

本机运行需要电脑保持开机、网络可用，登录后任务才能工作；定时聊天跟进还需要 Codex 桌面应用运行。睡眠、关机及断网的缺口如实记录。
