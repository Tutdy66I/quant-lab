## 第一周：仓库 + 第一份回测

- [x] 搭好仓库骨架（docs / notebooks / strategies / data）
- [x] 拉真实 BTC 历史数据（Kraken 日线，721 根）

- [ ] 读懂回测里的每个数字：收益、回撤、胜率、交易笔数分别意味着什么

**本周目标**：明白"回测"到底在测什么，以及为什么回测赚钱不等于实盘赚钱。

## 第二周：Hummingbot 纸面交易上线

原生 Python MA 观察器已补齐公开行情、持久化账本、后台运行和登录自启；Hummingbot 的系统安装与独立撮合验收继续单独推进，详见 [运行验收](运行验收.md)。

- [ ] 本地装好 Hummingbot，配好纸面交易模式（不连交易所）
- [ ] 跑一个最简单的策略（比如 pure market making 或均线策略的纸面版）
- [ ] 让它跑起来，开始记录模拟交易日志
- [ ] 每天看一眼日志，理解每一笔模拟成交是怎么产生的

**本周目标**：有一只"活着"的纸面机器人在跑，你能解释它的每一笔交易。

## 第三周：策略迭代

- [x] 把第一周回测里发现的问题（信号太少、回撤太大）变成具体的改进
- [x] 试 1-2 个改进方向：波动过滤、收盘亏损退出（次日开盘执行）
- [x] 每个改进单独回测，对比基线，用数字说话（见 [首轮实验报告](策略迭代报告.md)）
- [ ] 把表现最好的版本搬到 Hummingbot 纸面环境里跑

**本周目标**：亲手完成一次"发现问题 → 提出假设 → 回测验证 → 上线观察"的完整循环。

## 第四周：复盘 + 决定下一步

- [ ] 汇总四周的所有回测结果和纸面交易记录
- [ ] 写一份复盘：哪些假设被验证了，哪些被证伪了
- [ ] 诚实评估：这只机器人离"值得实盘"还有多远
- [ ] 决定下一步：继续优化、换策略方向、还是先停下来学更多理论

**本周目标**：不是"做出赚钱的机器人"，而是"学会用系统的方法做交易研究"。前者四周不够，后者四周够了。
