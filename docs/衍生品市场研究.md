# Quant Lab 2.1：独立市场状态研究

三个阶段的代码均已实现，只使用 Python 3.10+ 标准库。模块不导入或修改现有回测引擎、固定历史数据、Walk-forward 协议、纸面账户或部署配置；没有下单能力。统计模块目前输出真实的“数据不足”，不是已有预测价值的结论。

## 运行

在仓库根目录运行，每次采集都会在指定根目录下创建一个新版本目录：

```console
python -m strategies.derivatives_data collect --days 28
python -m strategies.derivatives_data verify data/derivatives/binance_btcusdt_v1/<快照目录>
python -m strategies.market_structure data/derivatives/binance_btcusdt_v1/<快照目录> --output data/derivatives/reports/<新报告目录>
python -m strategies.derivatives_study --output data/derivatives/<新研究目录>
python -m strategies.derivatives_pipeline
python -m unittest discover -s tests -v
```

`--root <目录>` 可指定独立采集根目录。`--days` 限定 1–28，默认 28 天；以采集开始时的 UTC 当日零点为上界，只请求已结束的完整日。现有快照和报告目录禁止覆盖。首次使用需将 `<快照目录>` 替换成 collect 输出的目录名。

单次采集命令仍可手动执行。已创建独立的 Codex 每日任务“quant-lab 衍生品每日采集与研究”，每天香港时间 08:15（UTC 00:15）运行 `python -m strategies.derivatives_pipeline`。任务需要本机 Codex 自动化执行环境可用，不是远程常驻服务；没有修改原纸面观察器的任务或其暂停状态。

自动流程默认只写 `runtime/derivatives/`（已被 Git 忽略）：`snapshots/` 保留每次采集的版本，`reports/` 保留市场结构报告、统计研究与运行状态，`latest.json` 原子更新最新状态。采集失败仍保存证据并运行已有快照的统计研究，返回非零退出码。每天只有一次有界重试的采集，不在地区限制下无限重试。相同 HTTP 451 和数据不足不重复通知；恢复、新的重要故障或首次实际验证结果才通知。运行文件不自动提交或推送。

`RUNNING` 文件防止并发运行。进程崩溃可能遗留锁；先核对文件中的 PID 及进程命令行，确认旧进程已结束后才清理锁。不能确定时保留并报告。每天保留新版本即可开始累积来源证据。接口暂未发布的数据会标成缺失，不补零或前向填充。

## 端点与 UTC 日期

| 数据 | 公开 GET 端点 | 时间语义 | 归入日期 D |
|---|---|---|---|
| 现货 BTCUSDT 日线 | `https://api.binance.com/api/v3/klines` | 开始及结束时间 | `[D, D+1)` 的已收盘价格 |
| USDⓈ-M OI | `https://fapi.binance.com/futures/data/openInterestHist` | 区间结束 | `D+1 00:00` 记录 |
| 全市场多空账户比 | `https://fapi.binance.com/futures/data/globalLongShortAccountRatio` | 区间结束 | `D+1 00:00` 记录 |
| 主动买卖量 | `https://fapi.binance.com/futures/data/takerlongshortRatio` | 区间开始 | `D 00:00` 记录 |
| 资金费率 | `https://fapi.binance.com/fapi/v1/fundingRate` | 结算事件 | `[D, D+1)` 内实际返回的事件 |

来源：[Binance USDⓈ-M 官方文档](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data)、[现货 K 线官方文档](https://developers.binance.com/docs/binance-spot-api-docs/rest-api/market-data-endpoints#klinecandlestick-data)。核对日期：2026-10-22。OI 可查询最近一个月，多空比和主动量为最近 30 天，不能当作多年数据库。资金费率使用独立端点，保留实际事件数量，不固定假设每天三次结算。

市场状态使用相邻完整日的现货收盘变化和 OI BTC 数量变化；若中间缺日，不跨缺口计算“一日变化”。美元名义 OI 保留，但不用于方向标签。多空比是账户数比，不是资金或仓位净多空。主动量不平衡为 `(buyVol - sellVol) / (buyVol + sellVol)`，总量为零时返回缺值。报告包含账户比、已观测费率之和与事件数；非空费率列表不代表日内事件已全部到齐。

## 快照与可重放证据

每个版本目录包含：

- `manifest.json`：版本、交易对、请求窗口、完整 URL、文档链接、每次 HTTP 状态和接收时间、原始文件名、SHA-256、完成或失败状态。
- `raw/*.bin`：响应原始字节，包括重试及失败响应；网络错误保存错误文本，不伪装成 HTTP 响应。
- `normalized.json`：校验成功后的独立 JSON 数据集。含原始时间戳、对齐日期、事件结束和实际观察时间。失败采集不生成此文件。

校验交易对、字段、有限数值、非负量、账户比例、日线 OHLC 与日界、请求范围和未结束数据。按时间排序，相同重复记录去重，冲突重复拒绝。数据缺日单列告警，空端点也保留缺失诊断。达到响应条数上限会拒绝发布，避免静默截断；本版窗口较短，不实现任意多年分页。

HTTP 顺序低速访问；网络错误、429、5xx 最多三次。尊重数值型 `Retry-After`；超过 60 秒则退出本端点并保存失败证据，留待后续重跑。418、451 和其他永久错误不重试。禁止使用密钥，不访问账户接口。

`verify` 离线检查原始指纹，重算规范化数据并逐字节比较。报告只从通过校验的快照生成，JSON/Markdown 可重复生成；报告内保存实际来源和计算结果。SHA-256 用于检测文件意外改动，不是第三方公证或防止有意同时重写 manifest 与数据的签名机制。

## 防止回补数据泄漏

每条记录 `available_at_ms = max(event_end_ms, HTTP接收时间)`。`market_structure --as-of-ms <毫秒>` 只使用该时点前已实际采集的记录。今天首次回补的过去数据，不能用于昨天的决策；默认报告允许描述过去同期关系，但不能因此宣称历史上已存在这些信号。

多次采集的版本分别存放，不覆盖旧值。阶段三按“指标、日期、实际采集时间”保留跨版本修订，在每个决策点选择当时已存在的版本；相同可用时间出现冲突值则拒绝研究，禁止将最新修订值回填过去。未来目标价格使用首次实际观测的版本固定，标签可用时间同样来自真实采集时间。失败快照不作为观测值；已声明完整却指纹损坏的快照会阻止研究，不能悄悄跳过。

## 阶段三：固定统计验证

独立协议为 `docs/derivatives_protocol_v1.json`，不修改原历史策略协议。程序内冻结参数，协议变化会拒绝运行，修订需要新版本。研究比较纯价格岭回归与增加衍生品特征的岭回归，不搜索模型或超参数。

| 项目 | 固定定义 |
|---|---|
| 决策时点 | UTC 零点，每 7 天一次；按 Unix 纪元固定网格，标签不重叠 |
| 特征日期 | 决策前最多两日，所有特征必须已实际采集；缺失则跳过该日 |
| 价格基线 | 相邻收盘收益、7 日动量、7 日收益总体标准差 |
| 增量特征 | OI BTC 数量变化、多空账户比、主动量不平衡、已观测资金费率和 |
| 训练 / 验证 | 252 / 63 个自然日滚动；最少 24 个训练样本 |
| 标签隔离 | 训练标签结束时间和实际可用时间均不得晚于验证窗起点 |
| 未来目标 | 7 日收益总体标准差、开盘及每日收盘路径最大回撤、未来收益与此前动量同号的比例 |
| 模型 | 训练集内标准化、固定岭惩罚 1.0、不惩罚截距 |
| 比较 | 完全相同验证日期上的 MSE/MAE 及配对平方误差改善 |
| 不确定性 | 固定种子 20261022，1,000 次循环区块重采样，每块 4 个周样本；少于 8 个验证预测不输出区间 |

每个验证窗保存训练/验证日期、训练标准化参数、模型系数、逐日目标和预测，来源保存快照 manifest 指纹。缺口不插值，不用未来标签训练，不借固定多年价格数据伪造过去可获得的衍生品信号。`--as-of-ms` 可固定研究截止时间；相同快照与截止时间可重放同样结果。

研究输出是条件预测误差诊断，不是带手续费的交易回测，不替换原 MA 基线。循环区块区间只作探索性不确定性描述；结构变化、缺失样本选择、资金费率事件完整性和多个目标比较都会限制解释。不能根据区间正负直接断言显著性、因果关系或自动部署。

首份真实状态报告：`data/derivatives/study_v1_initial/study.md`，0 个有效样本、0 个验证预测。完整训练窗和未来标签必须随实际采集时间积累，不能在本次开发中凭空完成；合成测试只用于检验计算和隔离逻辑。
