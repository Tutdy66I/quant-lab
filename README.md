# quant-lab

纸面交易机器人实验室：四周从零搭出一只可解释的纸面交易机器人。

> 全程模拟交易，不连接真实账户，不发起真实下单。

## 结构

```
quant-lab/
├── docs/        # 四周建造计划、复盘文档
├── notebooks/   # 回测 notebook（真实历史数据 + 中文解读）
├── strategies/  # 策略代码（每笔信号可解释）
└── data/        # 历史数据与回测结果（CSV/JSON）
```

## 第一份回测结果（BTC 双均线，2024-10-24 ~ 2026-10-14）

信号在日线收盘后确认，下一根日线开盘成交；每次买入和卖出各计 0.1% 手续费。

| 指标 | 数值 |
|---|---|
| 策略收益 | +3.4% |
| 买入持有 | -11.9% |
| 完成交易笔数 | 7 |
| 胜率 | 43% |
| 最大回撤 | 36.0% |

结论：计入下一根开盘成交和手续费后，双均线仍跑赢同期买入持有，但最大回撤达到 36.0%；这只是历史数据上的基线，不代表未来表现。
详情见 `notebooks/btc_ma_cross_backtest.ipynb`。
