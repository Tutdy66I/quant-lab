# 第39轮｜迟到特征的信息价值与跨机制分组贡献

## 契约与冻结范围

本轮在独立轻量合成目录开展。第38轮原始证据清单的227项全部核验；旧轻量入口原字节单独归档。第34轮 Ridge 参数与模型规则、第37轮发布状态和第29轮审计入口保持原判定。

特征事件包含特征ID、版本、来源身份、特征组ID、观测样本ID和数据集ID、观测时间、实际到达时间、修订序号及值。决策记录额外绑定决策样本、时点、实际使用的特征事件及其年龄。派生的滞后组保留上游观测时点。承诺覆盖原始特征和标签计划、完整合成样本全集及冻结配置。在线接口只接收当时的特征/标签事件。报告另以固定承诺和逐时重放核验原始轨迹、拟合时点、训练时预处理参数和模型版本。源与证据在本机同权限主体控制下，不能替代独立来源授权。

每个时点按事件优先级先接收特征、再输出预测、再接收标签、最后拟合下一时点生效的模型。真实可用时间等于传输到达的tick。最新观测超过6 tick只弃权；迟到观测可以作为随后合法决策的滞后量，训练只读此前合法输出的决策快照及已到达标签，无历史补收。修订需要原始事件、连续序号及更晚到达，只影响此后决策；修订是开发探针，不作为报告臂。无当前合法信息时在线记原因，离线才用受控模拟计划区分尚未送达和永久缺失。第34轮固定 Ridge 和定期 Ridge 使用原训练大小、候选 Alpha、训练内标准化及更新节奏。更新均值始终使用全部已到达标签，保持标签负对照；评价共享同一合法特征与评分掩码。

## 预注册比较

- 时效机制为共享 AR(1) 路径和同一目标关系。65%的预热后观测被分配到共同的迟到掩码，其余及时到达。注册即时、短迟2、长迟5、过期迟9、同掩码永久缺失、迟到并衰减、及时并衰减以及短迟但不准重用历史8臂。ttl=6的筛选按观测年龄，不按收到后已过时间。另有标签依赖目标大小及掩码的MNAR场景，只比较即时、短迟回用和短迟弃权。
- 分组机制为稳定、减弱、反转、消失、全无关、近重复、部分冗余且含独立增量、逐渐衰减、纯交互及薄训练下部分冗余10类。固定比较`base=x`、`full=x+g1+g2`、`single=x+g1`。全组删除是 full 与 base 的配对。稳定、部分冗余及纯交互中另测成对的严格过去12 tick组扰动；保持两个列的相对结构及顺序。没有增加交互基函数或改模型类别。20条初始标签的薄训练臂按24门槛退化。
- 开发种子69100–69103，把44个预设臂全量尝试，共176行开发结果。报告种子69600–69623与已知旧报告、开发种子无交集。没有按开发得分或新报告结果重新筛选注册臂。先锁源码、配置、历史基线摘要和配对规则，独立见证后才运行报告。
- 132个主要比较以独立种子为单位配对，固定t临界值5.5，至少18对；对整个比较族使用保守同时区间（依赖种子级t近似）。同路径的时点等样本不作为独立重复。时效衰减对照只用125起；组对照用90起。各主要比较固定时点范围，再在双方合法时点集合上相交。观察与人工真值差异分别保存。年龄分箱、成本、恢复额外覆盖和标签选择诊断均为次要描述。
- 所有单臂均经过第37轮状态机。默认120个计划时点、截止181，合法预测、标签到达、观察共同评分分别报告。出现弃权时仅能比较共同合法样本；MNAR不发布总体名次。本轮未预先定义弃权成本，因此没有把条件MSE变成总体效用或收益。

## 结果一｜迟到损失、恢复覆盖与真正失效

时效臂使用同一稳定预测关系的生成路径。下表MSE为各臂**自身合法点**上的均值。即时、短迟、长迟与两衰减臂均完整覆盖，各自可直接按相同范围比较。其他臂的MSE需要看共同点附录，不能用作全计划群组误差。

| 时效策略 | 平均合法预测、共同评分 / 120 | 固定 Ridge MSE | 定期 Ridge MSE | 更新均值 MSE |
| --- | ---: | ---: | ---: | ---: |
| 即时 | 120.00 | 0.129 | 0.137 | 1.734 |
| 短迟后按期重用 | 120.00 | 0.483 | 0.618 | 1.734 |
| 长迟后按期重用 | 120.00 | 0.610 | 0.795 | 1.734 |
| 同掩码永久缺失 | 113.75 | 0.572 | 0.700 | 1.720 |
| 同掩码过期后到达 | 113.75 | 0.572 | 0.700 | 1.720 |
| 短迟，只接受年龄0 | 41.83 | 0.125 | 0.127 | 1.707 |
| 及时到达但信号逐渐衰减 | 120.00 | 1.742 | 1.452 | 1.734 |
| 短迟且信号逐渐衰减 | 120.00 | 1.884 | 1.544 | 1.734 |

1. **即时变短迟、长迟的损失。** 以完整120点比较，固定 Ridge 配对MSE分别增加 **0.355 [0.250,0.459]**、**0.481 [0.309,0.653]**。定期 Ridge 分别增加0.481 [0.303,0.659]、0.658 [0.408,0.908]。在观察时效仍有效的人工AR机制下，这是信号可用性滞后的损失。固定与定期 Ridge 的领先者在即时变短迟及即时变长迟时各有8/24条翻转，系描述性比较。
2. **合规回用的价值。** 从只用年龄0切换到短迟后按期重用，平均多78.17/120个合法并已评分时点，种子级点态区间[75.80,80.53]，合法覆盖由34.9%到100%。在这些额外时点，固定 Ridge 用滞后特征的MSE为0.674，比同点只依标签的均值1.734低，仍高于即时特征的0.131。与更新均值的配对差−1.060 [−1.351,−0.768]，与即时固定Ridge的差+0.544 [0.488,0.599]，均为次要点态区间。共同已评分点上，固定 Ridge 不变，定期 Ridge 的短迟重用比弃权协议多0.250 [0.032,0.469]。这个差包括两协议带来的合法训练集合差异。额外覆盖与误差并列报告，无预注册弃权成本则不计算总体效用。
3. **陈旧与永久缺失。** 迟9的观测到达时年龄已大于6，截止前平均73.75条这样到达的评估期特征被标为过期。它与永久缺失臂的覆盖及误差逐条相同，偶尔还能用之前及时到达的最近合法观测。长迟臂的固定 Ridge 在年龄0、1–2、3–6的条件MSE为0.125、0.561、1.283；年龄箱的群体不同，只作条件描述。
4. **及时也可能失效。** 125后，及时衰减相对即时稳定特征，固定与定期 Ridge 分别增加2.789 [1.599,3.978]、2.252 [0.692,3.813]。控制相同短迟，衰减仍带来固定 Ridge +2.474 [1.290,3.659]。这是关系失效的独立证据。更新均值在相同点和相同标签计划下预测逐条相等；表中均值差异只来自评分点选择。

成本同样按计划范围记录。典型短迟臂处理180条输入事件，完整三列组处理540条。定期 Ridge 在正常可训条件下每路径24次候选拟合、每计划点评估费用0.001；更新均值每点预注册激活费用0.002；固定 Ridge无在线费用。拟合次数、事件处理量和本轮整项耗时是实测/登记量，费用惩罚未混入MSE。逐路径MAE、RMSE、合法特征比例、预测、标签返回及三方资格均在机器结果中保存。

## 结果二｜整组贡献与跨人工机制

以下是组增量对照，自tick90起。负值表示改善。固定稳定组和部分冗余组是两个不同的预注册生成机制，不把24条同种子重复当作新机制。

| 生成机制及对照 | 固定 Ridge ΔMSE（同时区间） | 定期 Ridge ΔMSE（同时区间） |
| --- | ---: | ---: |
| 情境关系稳定，整组 vs 无组 | −0.634 [−0.833,−0.436] | −0.717 [−0.960,−0.474] |
| 情境减弱，整组 vs 无组 | +0.088 [−0.036,+0.213] | −0.035 [−0.134,+0.064] |
| 情境反转，整组 vs 无组 | +1.533 [+1.109,+1.957] | +0.193 [−0.075,+0.461] |
| 情境消失，整组 vs 无组 | +0.449 [+0.276,+0.623] | +0.174 [+0.026,+0.322] |
| 情境逐渐衰减，整组 vs 无组 | +0.232 [+0.097,+0.367] | +0.009 [−0.062,+0.080] |
| 近重复，整组 vs 无组 | +0.011 [−0.019,+0.041] | +0.003 [−0.009,+0.015] |
| 部分冗余但含增量，整组 vs 单列 | −0.367 [−0.585,−0.149] | −0.394 [−0.506,−0.283] |
| 纯交互，整组 vs 无组 | +0.211 [−0.217,+0.639] | +0.132 [−0.129,+0.394] |
| 稀薄起始＋部分冗余，整组 vs 单列 | 0.000 [0,0] | −0.393 [−0.507,−0.280] |

- 稳定情境能复现；它的第二列主要替代首列，整组 vs 单列区间跨零。部分冗余的第二列携带不同的创新信息，固定和定期 Ridge 均有增量。换为整组同步的严格过去12 tick扰动后，部分冗余固定 Ridge 损失 +1.098 [0.715,1.481]，说明在这个机制下，当前时间匹配的数据比陈旧组更有价值。
- 近重复组平均相关0.99999161，标准化两列Gram条件数约27.3万，三列都获得相近的标准化权重；和不加入组相比无可靠增益。条件数刻画两列病态程度，不是完整模型数值评价，系数互相替代不支持单列因果归因。全无关场景也无可分辨增益。纯交互有结构信号，但加性Ridge不能表达其乘积项，实证未支持直接收益。
- 薄训练中固定模型从20标签以均值回退启动，整组与单列零差来自回退。定期模型取得足量反馈后可拾取组内信息，观察到了增益。该实验没有诱导出薄训练下这个三维有用组的过拟合，因此不能断言提高维度必然有害或无害。
- 标签MNAR时，即时与短迟重用的平均共同评分为57.21/120，只用年龄0为23.79/120。前两臂48组只准敏感性分析，第三臂24组证据不足。另有完整标签的短迟弃权4组未达到默认覆盖阈值。短迟MNAR下，固定和定期 Ridge 的应答数据排名相对合成真值有12/24次反转，只作选择偏差说明。覆盖率及评价群体变化可能造出表面改进，尤其年龄0筛选时自己的0.125 MSE并不能和完整群组0.483直接比较。

## 维护、验证和下一阶段

建议把真实到达水位、按观测年龄核验新鲜度、版本及修订链、不可修改的决策快照、训练内预处理承诺、固定计划分母与共同合法点门槛纳入长期维护。保留较窄的时效及成组诊断。停止使用单系数的重要性排名、不同覆盖样本的裸MSE比较和应答样本外推。下一步可在新机制上增加注重衰减速度的预注册检验，并检验相同覆盖下成组移除与时间扰动是否仍一致。暂不扩大特征搜索或改变三核心基线。
