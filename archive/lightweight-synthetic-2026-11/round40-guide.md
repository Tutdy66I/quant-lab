# 轻量合成研发统一使用与维护说明

## 用途和环境

适用于已审查的人工合成特征、标签、基线和发布资格。合成结果的解释范围由对应注册机制及目标样本定义。使用已核验的 **Windows CPython 3.10.11**，命令从包含本指南的轻量工作区运行。入口使用 Python 标准库及本地已核验 vendor 源码，不需要下载外部依赖。

```powershell
$syntheticPython = (Get-Command python.exe).Source
& $syntheticPython --version
& $syntheticPython -I -S -B .\run_synthetic.py
```

预期 320 项、0 跳过，摘要行以 `SYNTHETIC_SUMMARY` 开头。检查真实退出码、测试数、失败和跳过，再与历史测试身份核对。轻量入口拒绝在命令行加测试选择参数。解释器实际隔离、no-site 或禁止字节码写入状态缺失，或提供额外参数时退出 2。便携解释器的 _pth 可预置部分状态，维护命令仍明确传入三个参数，测试或受控导入失败时退出 1，全量成功退出 0。入口静态检查和 Python socket 防误用属于可信代码防护。进程未建立操作系统沙箱或独立网络隔离。

## 结构与同一时点的处理顺序

```text
预注册配置、固定种子
   → 人工样本全集清单、特征与反馈计划
   → 按到达时钟验证身份、版本、新鲜度
   → 预测和不可回填的决策快照
   → 已到达标签、训练内预处理、下一时点激活
   → 共同合法域计数、估计、R37 发布状态
   → 本地源/配置/日志/结果指纹与回执
```

先接收该时点合法可见的特征，再预测，之后接收标签与拟合。第 26 轮使用 `Sample` 和由全集指纹导出的身份，第 35–39 轮在线适配器用数据集限定的 tick 身份并核对相同总体与时钟。特征过去的观测时点和真实到账时间分开。迟到、修订、弃权、未返回标签、缺失和未知在适用的证据域内分开记录。排序和名称的共同语义由各代适配器校验，历史记录不改写字段。

固定 Ridge 保留最初合法模型，更新训练均值使用当时的标签，定期 Ridge 按冻结的时点与 `Alpha` 集合重训。三者是基线。第 39 轮标签均值用相同已到达标签负对照，特征可用性仍影响共同评分范围，因此单臂分数可能不同。原始自适应只在历史报告中对照，稳健报警用于诊断。时效、质量、储存及发布由不同模块负责，函数名相近不意味着早期和后期的轨迹字段可互换。

## 运行现有合成样例与查看历史

```powershell
& $syntheticPython -I -S -B .\smoke40.py
```

固定复跑第 39 轮开发种子 69100 的三个已存在的实验臂。期望共同评分数分别为 120、55、27，计划分母均为 120。命令检查旧开发记录中的评分资格与三个冻结基线 MSE，在 `round40-smoke-runs` 下为每次运行创建新的本地证据目录。错误时 Python 退出非零。回执的 `origin_authenticated` 是 false。其 `reviewer` 值是写入标签，审查角色由另存的执行记录说明。回执的源码指纹覆盖列出的直接依赖，完整交付版本由归档清单和全量回归的逐文件指纹验证。

已封存的报告使用对应 `roundNN-lock.json`、`roundNN-results.json`、原始日志及独立回执读取。报告种子预留目录用于拒绝重复报告执行；同种子运行仅能标记复现。不要删除或覆盖预留、历史报告或独立失败记录。第 29 轮审计入口保留作玩具流程对照，本指南的 E2E 使用证据写入及验证，未调用审计型留出评分。

## 研究发布状态

| 状态 | 证据可以支持的声明 |
| --- | --- |
| `valid_observed_only` | 仅描述共同应答样本，不外推总体。 |
| `population_supported_under_assumptions` | 仅在所列条件和目标域下支持总体估计。目标可以是计划总体，也可以是已验证预测子群；达到最低覆盖不会单独触发这一状态。 |
| `sensitivity_only` | 在登记的缺失假设与边界下讨论敏感性，不宣称点识别或总体冠军。 |
| `insufficient_evidence` | 证据或覆盖不足。保留分母、理由和弃权记录。 |
| `invalid` | 身份、时钟、摘要或证据不匹配。拒绝发布。输入违反调用契约导致异常时，同样没有可发布结果。 |

第 37 轮默认门槛为共同合法点至少 12 个且占计划范围至少 30%。应答充分性、重叠、有效样本量、时点稳定和识别假设仍要分开核对。总体资格与宣布配对赢家分别处理；区间跨零或方法冲突时继续保留不确定性。配对误差、覆盖与成本单列，分子不能通过缩小原计划分母提高。推断按预注册独立种子/路径处理，不能把序列中相关时点当作独立重复。块长度、权重截断和机制假设限定区间解释。高相关代理项系数不支持单独归因。
